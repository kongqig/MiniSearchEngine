# MiniSearch v2 — 个人可信网站目录搜索引擎

纯原生 HTML / CSS / JavaScript（ES Modules），无构建工具、无框架、无后端。
所有数据保存在本机（IndexedDB + localStorage），不上传任何信息。

## ⚠️ 更新版本后无法启动 / 报 `does not provide an export named` ？

这是**浏览器缓存了旧版模块**（同端口跑过旧版所致）或旧文件未覆盖完整，不是新包损坏：

1. `Ctrl + F5` 强制刷新（Mac：`Cmd + Shift + R`），或用**无痕窗口**打开；
2. 仍不行：删除旧文件夹 → 重新完整解压 → 服务指向新目录。

v2.2 起若模块加载失败，页面会自动弹出「页面未能启动」引导浮层（含一键重载与错误详情）。

## 快速开始

ES Modules 要求通过 HTTP 访问（直接双击 index.html 会被浏览器 CORS 限制）。

任选一种方式在项目目录启动静态服务：

```bash
# Python（推荐，无需安装）
python -m http.server 8080

# Node.js
npx serve .
```

然后浏览器打开 `http://localhost:8080`。

> 首次使用：打开「设置 → 字典管理」添加条目，或点击首页「载入示例条目」。

## 功能

- **本地字典搜索**：中文名、别名（v2.8）、标签、描述；全拼（weixin）、简拼（wxzf）均可命中
- **相关度排序**（v2.6）：匹配质量分档——完全相等 > 前缀 > 包含 > 词项覆盖，名字更纯粹的条目更靠前（搜「微信」时「微信」稳居「微信读书」前；搜「deepseek官网」只出 DeepSeek 相关结果，不再混入 edx/deepsearch）
- **别名（aliases）**（v2.8）：一站多名（中文名 / 英文名 / 昵称）存进同一个条目，与名称同样参与中文/全拼/简拼/连拼搜索，表单可编辑、列表可见、导出携带
- **搜索历史 / 收藏**（结果条目点 ★ 收藏；保存数量可设，超出自动删最旧，v2.5）
- **搜索引擎切换**：搜索框下方 字典 / 必应 / 百度 / 谷歌 / GitHub / 自定义 快捷切换条，选中即搜索目标（外部引擎回车直跳）；首页与结果页同步；自定义引擎在设置中填 URL 模板（{query} 占位符，缺省自动追加 ?q=）
- **搜索建议来源**（独立配置，默认来自本机字典，不随搜索引擎变化）：可选另配 百度 / 必应 / 谷歌 / 自定义建议接口——三个内置源均 JSONP 直连免跨域免代理（v2.4），在下拉顶部独立分组展示，失败自动回退字典；详见《交付说明》第七、十节
- **高级语法**：`site:gov.cn 社保`、`filetype:pdf 说明书`（本地过滤 + 外部引擎透传）
- **同网址导入策略**（v2.8）：字典管理「导入 / 导出」按钮旁五选一（v2.8.1 移入按钮行节省空间）——智能合并（默认，名称先到先得 + 补全空缺字段）/ 合并为别名（新名称入别名，条数不增加）/ 新数据覆盖（旧名称自动转别名保留可搜）/ 保留多条 / 完全跳过；判重只认规范化网址，子域名/路径不同全部保留不误合并（v2.7），标题相似/相同不判重
- **字典管理**：增删改查、导入导出；表单/确认框关闭后自动回到设置原面板，新增「保存并继续」批量录入（v2.5）；内置「JSON 格式与导入说明」帮助（字段必填/可选、追加导入、导入策略、无效跳过、拼音自动补算，v2.4/v2.8）
- **AI 回答（可选）**：OpenAI 兼容 / Gemini / Claude 协议，SSE 流式渲染，CORS 代理策略可调
- **工具卡片**：时间、日期、计算器、进制、单位、汇率、IP、随机数（按查询关键词触发）
- **主题**：浅色 / 深色 / 跟随系统、主题色、背景图、自定义 Logo
- **数据管理**：全量 / 仅字典的 JSON 导入导出；历史 / 收藏独立导入导出与保存数量设置（v2.5）；一键清除
- **双语界面**：中文 / English

## 技术要点

- 搜索：FlexSearch Document 索引（1w 条 p95 < 5ms），CDN 失败自动降级线性匹配
- 拼音：pinyin-pro 预计算字段（写入 IndexedDB 时完成），CDN 失败仅影响新增条目拼音
- 状态：单一 store + 订阅；事件集中于 `js/app.js` 委托分发

## 目录结构

```
index.html          入口页面
styles.css          全部样式（浅/深主题、响应式）
js/
  app.js            应用入口 + 集中事件绑定
  config.js         常量与默认配置
  store.js          单一 store + 持久化
  utils.js          通用工具
  i18n.js           双语文案
  ai/client.js      AI provider 注册表 + SSE 解析 + CORS 代理
  ai/answer.js      AI 回答编排（结果页侧栏）
  data/db.js        IndexedDB 封装
  data/repo.js      字典 / 收藏仓库（写入时预计算搜索字段）
  data/library.js   字典库维护（加载 / 重建索引 / 补算）
  search/precompute.js  拼音预计算
  search/indexer.js     FlexSearch 索引层
  search/query.js       site:/filetype: 解析 + 引擎 URL
  search/service.js     搜索编排（缓存 / 分页 / 路由）
  tools/cards.js        工具卡片（含无 eval 计算器）
  ui/dom.js             主题 / Logo / toast
  ui/engine.js          引擎快捷切换条（双页同步）
  ui/home.js            首页视图
  ui/suggestions.js     建议下拉（首页 / 结果页）
  ui/results.js         结果页视图
  ui/dialogs.js         对话框（历史/收藏/条目表单/确认；子对话框自动恢复底层面板）
  ui/settings.js        设置面板（8 个子面板，含帮助中心）
```
